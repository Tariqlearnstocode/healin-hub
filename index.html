For context

Why a rebuild, not a patch

We audited the current site before scoping this. Four findings made from-scratch the only honest recommendation:

✕Stock templateA generic ListingPro WordPress theme, lightly configured — nothing custom to build on.
✕No geographic dataListings were never geocoded, so distance search has never worked and can’t be turned on.
✕Unfinished contentTest listings, placeholder text, and dead links are still live on the site today.
✕Compromised installInjected spam links across pages — the kind of thing Google penalizes a domain for.

In the new build, none of these are fixes — they’re the foundation. Geocoding, real content, and security are built in from line one.
